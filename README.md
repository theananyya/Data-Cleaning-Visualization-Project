# Data Cleaning & Visualization Project

## Overview
Data quality plays a crucial role in extracting meaningful insights from raw datasets. This project focuses on cleaning, preprocessing, and visualizing a sales dataset using Python.
The workflow includes identifying missing values, removing duplicate records, preparing the dataset for analysis, and generating visual reports to better understand data patterns and relationships.

## Project Goals
* Improve data quality through preprocessing
* Handle missing values efficiently
* Detect and remove duplicate records
* Perform exploratory data analysis (EDA)
* Create visualizations for better decision-making

## Tools & Libraries
* Python
* Pandas
* Matplotlib
* Seaborn

## Project Workflow

### 1. Data Loading
The raw sales dataset is imported using Pandas for further processing.

### 2. Data Cleaning
* Missing numerical values are replaced with column means.
* Missing categorical values are replaced with the most frequent value (mode).
* Duplicate records are identified and removed.

### 3. Data Export
The cleaned dataset is stored for future analysis.

### 4. Data Visualization
Three different visualizations are generated:
1 Distribution Plot
Analyzes the distribution of numerical data.

2 Scatter Plot
Shows relationships between numerical variables.

3 Correlation Heatmap
Displays correlation strength among numerical features.

* Scatter Plot
* Correlation Heatmap
